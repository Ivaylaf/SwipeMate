SwipeMate - readMe.txt
=====================

1. Какво съдържа флашката / архива
- PDF версия на документацията
- Редактируема версия на документацията
- Целия проект SwipeMate
- Този readMe.txt файл

2. Предназначение на проекта
SwipeMate е учебен дипломен проект и в настоящия си вид е подготвен основно за локална демонстрация и защита. Приложението не е публикувано в публична cloud среда. За да бъде тествано, е необходимо локално стартиране на backend частта, мобилния клиент и връзка към PostgreSQL база данни.

3. Необходими условия за стартиране
- Windows компютър с инсталиран Visual Studio 2022
- .NET 9 SDK
- .NET MAUI workload
- PostgreSQL
- Android Emulator и/или Windows Machine

4. Настройка на базата данни
- Създава се PostgreSQL база данни с име `swipemate`
- В `SwipeMate.Api/appsettings.json` се задава правилният connection string
- При стартиране на API проекта миграциите и началните данни се прилагат автоматично

5. Стартиране на проекта
1. Отворете решението `SwipeMate.sln` във Visual Studio 2022.
2. Задайте startup project на `SwipeMate.Api`.
3. Стартирайте `SwipeMate.Api`.
4. Уверете се, че API проектът работи на локален адрес.
5. След това задайте startup project на `SwipeMate.Mobile`.
6. Стартирайте мобилния клиент на `Windows Machine` или `Android Emulator`.

6. Адрес на backend сървъра
- За `Windows Machine` се използва:
  `http://localhost:5274`
- За `Android Emulator` се използва:
  `http://10.0.2.2:5274`

7. Първо тестване
За първоначална демонстрация е необходимо:
- да стартирате API проекта
- да стартирате мобилния клиент
- да създадете поне два потребителски акаунта
- да добавите единия потребител като приятел на другия
- да създадете групова сесия
- да приемете поканата от втория акаунт
- да зададете филтри и да започнете swipe гласуване

8. Демонстрационни данни
- Системата seed-ва роли `User` и `Admin`
- Seed-нат администратор:
  username: `admin`
  password: `admin123`
- В каталога има примерни данни за:
  - Movies & TV
  - Restaurants
  - Recipes
  - Board Games

9. Основни функционалности
- регистрация и вход
- приятели и заявки за приятелство
- създаване на групови сесии
- покани към участници
- филтри по категории
- swipe гласуване
- match история
- профил и роли

10. Бележка
При бъдещо развитие проектът може да бъде публикуван в cloud среда, като тогава локалните URL адреси ще бъдат заменени с публичен backend адрес.
