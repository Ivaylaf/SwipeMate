SwipeMate - инструкции за стартиране
====================================

1. Съдържание на проекта
------------------------
В папката на проекта се намират:
- SwipeMate.sln - Visual Studio solution файл;
- SwipeMate.Api - backend частта на приложението;
- SwipeMate.Mobile - мобилното приложение, разработено с .NET MAUI;
- Documentation - материали и документация към дипломния проект;
- Tools - помощни скриптове;
- readMe.txt - текущият файл с инструкции.

2. Публичен backend адрес
-------------------------
Backend частта е публикувана онлайн чрез Render:

https://swipemate-api.onrender.com

Базата данни е PostgreSQL и е разположена в Supabase. Мобилното приложение е настроено
да използва този онлайн адрес автоматично. Във финалния вариант не е необходимо да се
стартира локално SwipeMate.Api, за да се демонстрира приложението.

Важно: при безплатния план на Render първата заявка може да се забави, ако услугата е
била неактивна. При първо влизане или регистрация е нормално да се изчака около 30-60
секунди.

3. Необходими програми за разработка
------------------------------------
За отваряне и стартиране на проекта локално са необходими:
- Windows 10/11;
- Visual Studio 2022;
- .NET 9 SDK;
- .NET MAUI workload;
- Android Emulator или Windows Machine target;
- интернет връзка за достъп до онлайн backend-а.

4. Стартиране на мобилното приложение
-------------------------------------
1. Отваря се SwipeMate.sln във Visual Studio 2022.
2. Като startup project се избира SwipeMate.Mobile.
3. Избира се target:
   - Windows Machine за демонстрация на компютър;
   - Android Emulator за демонстрация като мобилно приложение.
4. Натиска се Start.
5. Създават се два потребителски акаунта или се влиза със съществуващи.
6. Потребителите се добавят като приятели.
7. Създава се сесия, избира се приятел, задават се филтри и се изпраща покана.
8. Вторият потребител приема поканата, задава свои филтри и участва в гласуването.
9. При съвпадение между участниците резултатът се записва в историята.

5. Локално стартиране на backend-а, ако е необходимо
----------------------------------------------------
Ако трябва да се тества локално:
1. Стартира се PostgreSQL база данни.
2. В SwipeMate.Api/appsettings.Development.json се задава локален connection string.
3. Като startup project се избира SwipeMate.Api.
4. Стартира се API проектът.
5. За Windows Machine локалният адрес е:
   http://localhost:5274
6. За Android Emulator локалният адрес е:
   http://10.0.2.2:5274

Финалният мобилен проект обаче е настроен да използва онлайн адреса на Render.

6. Администраторски акаунт
--------------------------
Системата създава административен акаунт за демонстрация:

username: admin
password: Admin123!

Администраторът може да преглежда потребители и каталожни предложения, както и да
блокира/отблокира потребители и да активира/деактивира предложения от каталога.

7. Основни функционалности за демонстрация
------------------------------------------
- регистрация и вход;
- редакция на потребителски профил;
- добавяне на приятели;
- изпращане и приемане на покана за групова сесия;
- филтриране по категории: филми и сериали, ресторанти, рецепти и настолни игри;
- гласуване чрез swipe логика;
- записване на съвпадения;
- история на сесиите и съвпаденията;
- административен панел;
- backup/export на данни.

8. Backup/export на базата
--------------------------
В административния панел има възможност за създаване на JSON export на основните данни.
Експортът не включва паролни хешове.

При нужда от пълен PostgreSQL backup може да се използва pg_dump или export инструментите
на Supabase.

9. Забележки
------------
Проектът е учебен дипломен проект. Публикуването в Google Play не е задължително за
демонстрация. Практическият резултат се показва чрез работещо мобилно приложение,
онлайн backend и cloud PostgreSQL база данни.
