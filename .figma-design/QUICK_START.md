# SwipeMate - Quick Start Guide

## 🚀 Getting Started

### Step 1: Login
- Enter any username and password
- Or click "Sign up" to register a new account
- You'll be automatically logged in

### Step 2: Welcome Tour
- A welcome modal will appear explaining the key features
- Click "Get Started" or the X to dismiss
- You can access it again by clicking the ❓ icon in the top right

### Step 3: Choose Your Adventure

#### Option A: Quick Solo Browse
1. Click any category card (Movies, Restaurants, Recipes, or Board Games)
2. Click "Continue to Filters" without selecting friends
3. Set filters or skip by clicking "Start Swiping"
4. Swipe through options!

#### Option B: Match with Friends
1. First, go to "Friends" and accept the pending friend requests
2. Return to Home
3. Click a category
4. Select one or more friends
5. Click "Continue to Filters"
6. Set your preferences
7. Start swiping!

## 📱 How to Swipe

### Desktop
- Click the ❤️ button to like
- Click the ✕ button to reject
- Or drag cards left/right with your mouse

### Mobile/Tablet
- Tap the ❤️ button to like
- Tap the ✕ button to reject
- Or swipe cards with your finger (most fun!)

## 🎯 Getting a Match

When you like an item:
- In this demo, matches happen automatically
- You'll see a celebration screen
- The match is saved to your history
- In a real app with friends, all participants would need to like the same item

## ❓ FAQ

**Q: Do I need to select friends?**
A: No! You can swipe solo to browse content.

**Q: How do matches work?**
A: In this demo, liking any item creates a match. With a backend, all participants would need to like the same item.

**Q: Can I change my filters mid-session?**
A: Currently no, but you can go back and start a new session.

**Q: Where is my data stored?**
A: In memory only - it resets when you refresh the page.

**Q: Can I add real friends?**
A: This is a demo, but you can "add" mock friends by username.
